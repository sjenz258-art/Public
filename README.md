# 百數小花園

Touch-friendly Traditional Chinese hundred-chart games for children, built with plain HTML, CSS, and JavaScript.

- Find the Number: configurable countdown or ten-number speed race.
- Missing Numbers: ten selectable levels, hiding 5–50 numbers, with 300 seconds per level.
- Congratulations, next-level progression, pause/resume, optional sound, and progress saved locally on each device.

Open `index.html` in a browser to play locally. The optional Google font requires an internet connection; system fonts are used as a fallback.

## GitHub Pages

In the repository's **Settings → Pages → Build and deployment**, select **GitHub Actions**. Push to `main`, or run the **Deploy to GitHub Pages** workflow manually. It publishes the three application files and leaves repository metadata out of the deployed site.

No build tools, accounts, or backend are required by the game. Progress does not sync between devices.
